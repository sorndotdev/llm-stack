# llm-stack

Personal workspace of custom skills, agents, and API scripts.

## Install

```sh
./install.sh
./install.sh --update
```

Copies `skills/` and `agents/` into:

- `~/.claude/skills` and `~/.claude/agents`
- `~/.config/opencode/skills` and `~/.config/opencode/agents`

`--update` overwrites only entries that exist in this repository. Unrelated entries are left untouched.
