Personal workspace of custom skills, agents, and API scripts

## Install

Run `./install.sh` to symlink `skills/*` and `agents/*.md` into `~/.claude/` and `~/.config/opencode/`. `agents/global.md` installs as `~/.claude/CLAUDE.md` and as an OpenCode agent. `hooks/*` link into `~/.claude/hooks/` only; identical copies there are replaced. Re-run after adding, renaming, or removing a skill, agent, or hook.
